## 📅 Weekly Breakdown

### 🧱 Week 1: Foundations

| Day | Topic | Resources |
|-----|-------|-----------|
| 1–2 | 🚀 Getting Started – Installation, Cargo, Playground | [Rust Book Ch1–3](https://doc.rust-lang.org/book/) |
| 3–4 | 🧠 Ownership – Borrowing, References | [Rust Book Ch4](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html) |
| 5–6 | 🔁 Control Flow – Functions, Match, Loops | [Rust Book Ch3–5](https://doc.rust-lang.org/book/ch03-00-common-programming-concepts.html) |
| 7   | 🛠️ Mini Project – CLI Calculator | Practice building with inputs & functions |

---

### 🧰 Week 2: Structuring Data

| Day | Topic | Resources |
|-----|-------|-----------|
| 8–9 | 🏗️ Structs & Enums – Data modeling | [Rust Book Ch5–6](https://doc.rust-lang.org/book/ch05-00-structs.html) |
| 10–11 | 📚 Collections – Vec, HashMap | [Rust Book Ch8](https://doc.rust-lang.org/book/ch08-00-common-collections.html) |
| 12–13 | ❌ Error Handling – Result, Option | [Rust Book Ch9](https://doc.rust-lang.org/book/ch09-00-error-handling.html) |
| 14 | 🛠️ Mini Project – Contact Manager (HashMap + Result) | Apply collections + error handling |

---

### ⚙️ Week 3: Async & Crates

| Day | Topic | Resources |
|-----|-------|-----------|
| 15–16 | 🔀 Concurrency – Threads, Mutex, Arc | [Rust Book Ch16](https://doc.rust-lang.org/book/ch16-00-concurrency.html) |
| 17–18 | 🌐 Async Rust – Futures, tokio | [Tokio](https://tokio.rs/), Rust Async Book |
| 19–20 | 📦 Crates – Using external libraries | [Crates.io](https://crates.io/) |
| 21 | 🛠️ Mini Project – Async Web Scraper (reqwest + tokio) | Web scraping in Rust! |

---

### 🧪 Week 4: Advanced & Final Project

| Day | Topic | Resources |
|-----|-------|-----------|
| 22–24 | 🧬 Advanced – Macros, Unsafe, FFI | [Rust Book Ch19](https://doc.rust-lang.org/book/ch19-00-advanced-features.html) |
| 25–27 | ⚡ Optimization – Lifetimes, Smart Pointers | [Rust Book Ch10 + Ch20](https://doc.rust-lang.org/book/) |
| 28–30 | 🏁 Final Project – Combine All Skills | Ideas below 👇 |

## 📌 Tips for Success

- ✅ Stick to 1 hour daily, avoid burnout
- ✅ Don’t skip projects – they reinforce learning
- ✅ Bookmark and revisit errors, patterns, and concepts
- ✅ Join [Rust Discord](https://discord.gg/rust-lang) and [r/rust](https://www.reddit.com/r/rust/) for community help
